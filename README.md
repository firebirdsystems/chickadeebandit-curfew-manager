# Curfew Manager

A [Chickadee Bandit](https://chickadeebandit.com/app-library/curfew-manager) app.

Adults set per-child curfew times by weekday and weekend. Kids see their schedule and can request one-time exceptions. Parents approve or deny in-app.

## Features

- Per-child curfew times for weekdays and weekends.
- Kids see their own schedule.
- One-time exception requests from kids.
- Parents approve or deny in-app.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-curfew-manager/releases/latest/download/bundle.json
```
